# AI-powered-Oracle-DBA-Copilot
AI-powered Oracle DBA Copilot built with LangGraph, LangChain, Ollama, and Oracle Database. Perform database health checks, tablespace monitoring, Data Guard validation, FRA monitoring, and blocking session analysis using natural language queries.

Overview

Oracle DBA AI Copilot allows database administrators to ask questions in plain English and receive diagnostic insights from Oracle databases.

Instead of manually running SQL queries, DBAs can interact with the assistant using commands such as:

"Check tablespace usage"
"Show blocking sessions"
"List invalid objects"
"What's the Data Guard status?"
"Check FRA utilization"

The AI agent automatically selects the appropriate diagnostic tool, executes the SQL query, and provides a summarized response.
